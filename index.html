Langkah 1 dari 3 · File soal

Langkah 1

Masukkan file soal

Gunakan file Excel atau CSV yang berisi pertanyaan dan pilihan jawaban.

File soal akan dibaca di browser pada tahap berikutnya.

Langkah 2

Soal ini ingin dimasukkan ke mana?

Pilih salah satu tujuan formulir.

Pilih file dan tujuan formulir untuk melanjutkan.

Sebelum mulai

  • • Siapkan file Excel berisi soal.
  • • Pastikan pilihan jawaban tersusun rapi.
  • • Jika memakai Form yang sudah ada, pastikan kamu memiliki akses edit.

Tentang aplikasi ini

Aplikasi ini membantu guru dan pengguna umum memasukkan soal ke Google Forms tanpa mengetik ulang secara manual.
